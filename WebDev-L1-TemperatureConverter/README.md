# Oasis Infobyte - Task 3
## Temperature Converter Website

This project is created as part of the Oasis Infobyte Web Development Internship.

### Project Description

The Temperature Converter is a simple and responsive web application that allows users to convert temperatures between:

- Celsius
- Fahrenheit
- Kelvin

### Features

- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Simple and clean user interface
- Responsive design
- Clear button to reset the converter
- Input validation for incorrect values

### Technologies Used

- HTML5
- CSS3
- JavaScript
